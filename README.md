## Проекты

### 1. Olist — SQL-анализ маркетплейса

[Репозиторий](https://github.com/Leekor-byte/olist-sql-analysis) · SQL (SQLite), Python, Pandas, Matplotlib, Seaborn

Анализ 100 тысяч заказов бразильского маркетплейса: выручка, категории, логистика, отзывы, клиенты.

- **Рост остановился.** Выручка вышла на плато (~1,1 млн BRL/мес с марта 2018), значит, расти можно только через средний чек и удержание, а не через привлечение.
- **Логистика — прямой рычаг рейтинга.** Доставка в срок: оценка 4,29. С опозданием: 2,57 (−1,72 балла). Всего 7,7% опоздавших заказов формируют основную массу оценок 1–2.
- **Классический retention здесь не работает.** Удержание 0,2–0,7% в месяц: это маркетплейс разовых покупок. Предложил категорийные триггеры вместо реактивации.
- **Среднее искажает картину.** Средний срок доставки 12,6 дня, но медиана 10, p90 — 23, максимум — 210. Предложил KPI: медиана и p90 вместо среднего.
- **Клиенты делятся на два уровня чека** (~230 и ~47 BRL). Приоритетный сегмент — «В зоне риска»: 22 943 клиента с высоким чеком и низкой свежестью покупки.

Технически: 11 SQL-запросов (CTE, оконные функции RANK и NTILE, подзапросы), вынесены в отдельную библиотеку `.sql`-файлов; когортный анализ и RFM-сегментация.

### 2. Superstore — интерактивный дашборд в Power BI

[Репозиторий](https://github.com/Leekor-byte/superstore-sales-dashboard) · Power BI, DAX, Power Query, моделирование данных

Дашборд из трёх страниц (Executive Summary, Product Analysis, Regional Insights) на 10 тысячах записей. Модель данных — star schema: отдельные таблицы измерений для продуктов, клиентов, географии и календаря. Написал 10+ мер на DAX: YoY, YTD, Profit Margin, Avg Order Value, Sales PY.

- Подкатегория **Tables убыточна**: маржа −8,56% при выручке $206K.
- Регион **Central отстаёт**: $7,5K прибыли при $147K продаж в 2014 году.
- Пик продаж приходится на сентябрь, ноябрь и декабрь.

### 3. Маркетинговые каналы и A/B-тест — учебный кейс Т-Банка

Python, Pandas, SciPy, Seaborn, Matplotlib, Power BI, DAX

Кейс из курса по анализу данных: задания выполнил сам на данных курса.

- **A/B-тест:** в тестовой группе конверсия оформления карт выросла на 15% (p < 0,0001; Z-тест, биномиальный тест и T-тест). Обосновал рекомендацию по раскатке.
- **Юнит-экономика:** рассчитал CAC, LTV и ROI по 6 каналам (1 800 клиентов). Лидер — таргетная реклама (ROI 49%), убыточный канал — e-mail (ROI −6%).
- Собрал дашборд в Power BI с динамическими метриками.

### 4. Анализ датасета покемонов — ML пет-проект

[Репозиторий](https://github.com/Leekor-byte/pokemon-analysis) · Python, Pandas, NumPy, Scikit-learn, SciPy, Jupyter, Git
